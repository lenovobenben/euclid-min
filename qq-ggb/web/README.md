# 12 E 交互式作图展示

下载 [index.html](index.html)，再用现代浏览器打开。在 GitHub 上，文件链接显示源码；请使用文件页面的下载按钮保存 HTML。它是包含全部样式、代码、图形数据及精确证书的单个 HTML 文件，无需安装、联网或启动服务器；给别人展示时只需发送这个文件。

网页支持平移缩放画面，构造点的位置固定。需要拖动初始点、查看原生尺规依赖时，使用 [GeoGebra 演示](../ggb/README.md)。

## 操作

- 播放 / 暂停，上一笔 / 下一笔，点击时间轴跳转到 0–12 E；支持 0.5–2 倍速。
- 拖动画面平移，滚轮或右下角按钮缩放，取景按钮恢复本步画面。
- “点名”“辅助线”控制显示；第 12 笔完成后可“聚焦结果”。初始圆与当前一笔始终保留。
- 空格播放，左右方向键逐步，Home 回到初始条件，End 跳到结果。键盘焦点在按钮、滑块、下拉框中时，保留控件自身的键盘操作。
- 信息按钮显示来源、计数规则，可下载证书或保存离线网页。

界面适配桌面与手机。视觉参考项目 [Manim 动画](../../animations/e17/e17_progress.py)：深蓝底、洋红初始圆、金色当前一笔、淡蓝旧图元、粉色圆心与半径提示、绿色结果标注。

## 几何与计数

展示基于 [construction-12e-011.json](../construction-12e-011.json)，共 3 条直线、9 个付费圆。免费给出 O、A 与单位圆，交点免费。第 12 E 同时得到 A 的两个相邻顶点 B₊、B₋；绿色半径与角度弧只是结果标注，不是额外作图动作。没有声称 12 E 最小。

原始 GGB 由 QQ 讨论组网友提供给用户，首创者未确认。本版本修改了 K、P 的交点分支，让原有十二笔直接得到指定相邻顶点，省去首次 15 E 转换方案追加的三个圆。原图本身也是 12 E；具体贡献见 [方案比较](../README.md#本项目改了什么价值在哪里)。界面使用项目初始点名 O、A，原 GGB 的辅助点 O 在界面改名为 U，最终 Q、R 显示为 B₊、B₋。

生成器先用 Sage 的精确代数数重放实际证书，校验构造与规则摘要，再与独立证书重放器逐一比较全部 18 个点。步骤输入必须已经可用，交点在其两个来源图元都出现时即可显示。

所有作图、求交、分支选择与正确性判断使用精确计算。仅在输出画面数据时，将精确代数数按整数取整序列化为 12 位十进制字符串。浏览器的 Number 只用于屏幕投影、裁剪、标签排版和动画，不参与几何求交或正确性判定。缩放和平移不会更改构造。

## 重新生成

在仓库根目录运行以下 PowerShell 命令：

```powershell
$qqWebSageImage = 'sagemath/sagemath@sha256:4f5589eb6c565949a006f8665de2876b8414410daf5ac554f4434a15d4f3d528'
docker run --rm --network none -v "${PWD}:/workspace" -w /workspace -e PYTHONPATH=/workspace/sage -e PYTHONDONTWRITEBYTECODE=1 $qqWebSageImage sage -python qq-ggb/web/export_web.py
```

修改 `template.html`、`style.css`、`player.js` 后重新生成，不直接编辑 `index.html`。输出包括单文件网页、`geometry.json` 和精确导出核验记录 `export-report.json`。
