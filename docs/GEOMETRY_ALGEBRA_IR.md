# 正十七边形几何—代数统一 IR

## 1. 目的

现有 verifier 已经能够回答：给定一份尺规程序，它是否合法、花费多少 E、是否
精确命中目标？但从代数分解反向生成短作图，还缺少一个关键中间层。

原因是 E 成本不属于孤立的“加法、乘法、开平方”，而属于整个几何上下文：

- 已画出的直线或圆可以继续复用；
- 一笔新对象与全部已有对象的有限实交点自动免费出现；
- 一只 Carlyle 圆通常同时给出一对根；
- 同一个代数量可以由多个点和多张坐标图承载；
- 证书何时给交点命名，不等于这个点最早何时已经可用。

因此本项目不为“解一个二次方程”规定固定 E 单价，而把状态写成

\[
S=(P,D,R),
\]

其中 `P` 是已有点，`D` 是已有直线和圆，`R` 是代数符号的几何表示。候选程序
在状态 `S` 上的成本由实际新增的不同对象数决定；正式 profile 仍对重复绘制收费，
但最短路线不会从重复绘制中获益。

## 2. 第一份运行中的 IR

文件
[geometry-algebra-ir.json](../baselines/regular-17/detemple-1991-carlyle-improved-converted/geometry-algebra-ir.json)
由
`sage/experiments/build_regular17_geometry_algebra_ir.py`
从已验证 19E 证书确定性生成。它包含：

- 19 个付费对象的逐笔转移；
- 每笔定义点的真实出生 E 步；
- 20 个对象（含免费单位圆）的完整有限实交点安排；
- 每个点的稳定 ID、别名和全部关联对象；
- 四层二次关系、几何载体与精确 AA 核对；
- 7 个连续宏的上下文成本；
- 从当前目标桥反向抽出的代数与几何活跃切片。

本次完整闭包共得到 180 个点。除初始两点外，证书显式绑定 22 个交点，另有
156 个免费闭包点从未命名。IR 使用真实出生时刻，不把未命名点误算为不存在。

## 3. 二次塔

19E 路线使用的代数主干可写成以下机器可执行关系：

| 关系 | 两根或输出 | 根和 / 定义 | 根积 |
|---|---|---|---|
| 半尺度 `eta_2` | `eta0_2_half, eta1_2_half` | `-1/2` | `-1` |
| 恢复尺度 | `eta0_2` | `2*eta0_2_half` | — |
| 恢复尺度 | `eta1_2` | `2*eta1_2_half` | — |
| 偶 `eta_4` 对 | `eta0_4, eta2_4` | `eta0_2` | `-1` |
| 奇 `eta_4` 对 | `eta1_4, eta3_4` | `eta1_2` | `-1` |
| 最终 `eta_8` 对 | `eta0_8, eta4_8` | `eta0_4` | `eta1_4` |

其中

\[
\eta_{0,8}=2\cos\frac{2\pi}{17}.
\]

表达式使用 `rational`、`symbol`、`add`、`mul`、`neg` 和 `div` 组成的树；生成器
在 Sage `AA` 中逐式核对，不以字符串公式或浮点近似作为证据。

## 4. 第一个结构结论

当前 19E 基线从 `eta4_8` 反向切片时，6 条关系全部活跃；8 个二次根中有 5 个
被后续消费，3 个是同一笔作图免费产生的兄弟根：

- `eta2_4`；
- `eta3_4`；
- `eta0_8`。

最后一个尤其重要：第 17E 的 `c_M0_4_Ay` 已经在横轴上免费产生
`eta0_8=2*cos(2*pi/17)`，只是证书没有给这个交点命名。现有 19E 尾部实际使用
另一个根 `eta4_8`，再花 2E 把目标转移到单位圆。

这说明下一阶段不是“继续求出目标余弦”；目标迹已经存在。真正的优化问题是：

> 能否改变几何载体或提前留下可复用痕迹，用更少对象把已知目标迹编译成单位圆
> 上的相邻顶点？

## 5. 固定前缀的局部穷尽

### 5.1 固定 17E 前缀的一步穷尽

`search_e17_one_step_target_extension.py` 对已验证路线的固定 17E 状态完成了第一项
精确有限搜索。该状态有 147 个不同点，搜索按精确字典序覆盖：

- 10,731 个无序点对定义的直线参数化；
- 21,462 个有序点对定义的圆参数化；
- 合计 32,193 个合法基础操作参数化。

分片路径先用精确共线式和等距式检查两个目标，再排除已有对象。独立参考路径则
完整生成 30,021 个不同新对象，逐个调用 `contains` 检查目标。两路一致：

- 15 个目标关联参数化全部只是重复画已有单位圆；
- 不存在经过任一目标的新直线或新圆；
- 因而这个固定 17E 前缀不能只加 1E 形成 18E 构造。

正式摘要位于
`benchmarks/e17-one-step-target-extension-sage-10.7.json`。这个结论只排除
“固定前 17E + 一笔”的局部路线，不排除不同的 18E 前缀，也不是全局下界。

### 5.2 固定 16E 前缀的两步穷尽

`search_e16_two_step_target_extension_v2.py` 已经精确覆盖已验证路线固定 16E
状态之后的全部至多两笔扩展。父状态含 128 个不同点、7 条直线和 10 个圆；它
本身不存在一步目标候选。因此，如果一个两步扩展首次命中目标，末笔必然使用
倒数第二笔产生的至少一个新交点：完全由旧点定义的末笔在父状态中已经可画。

搜索按确定性顺序完整覆盖：

- 22,454 个不同的倒数第二笔对象，其中 7,219 条直线、15,235 个圆；
- 各子状态中至少使用一个新点的 202,855,848 个末笔参数化；
- 28,072 个由新单位圆交点参数化出的圆按 provenance 严格识别为重复单位圆；
- 其余目标入射式由严格实区间排除，全程没有遗留 `deferred` 关系；
- 最终没有任何不同的新直线或新圆经过 `B_plus` 或 `B_minus`。

所以，现有已验证路线的**固定前 16E**不能用至多 2E 完成目标；若要得到 18E，
必须在第 16E 或更早改变前缀，而不能只替换现有最后三笔中的两笔。正式摘要位于
`benchmarks/e16-two-step-target-extension-v2-sage-10.7.json`，候选级哈希链日志
位于 `benchmarks/e16-two-step-target-extension-checkpoint-v2-sage-10.7.jsonl`。

这个结论穷尽的是一个固定有限状态之后的全部两步选择，不排除其他 16E 前缀，
也不能升级为全局 18E 下界或“19E 最优”的证明。

## 6. 可暂停与恢复协议

固定 17E 一步搜索使用 `euclid-min-sharded-search-checkpoint/v1`：

1. 任务签名固定 profile、输入文件 SHA-256、算法脚本 SHA-256、配置和完整分片表；
2. 主进程只在一个分片完全结束后记录结果；
3. 检查点先在同目录临时文件写完并 `fsync`，再原子替换；
4. 死机发生在分片中间时，只重算当前分片；
5. 输入、代码、配置或分片安排变化时拒绝续跑；
6. `Ctrl+C` 或 `--max-shards` 会把任务标记为 `paused`；同一命令自动从剩余分片继续；
7. 每个分片保留计数和候选，因此长任务在跑完前也有可汇总的中间结论。

固定 17E 搜索的完成检查点位于
`benchmarks/e17-one-step-target-extension-checkpoint-sage-10.7.json`，126 个分片
全部完成。

固定 16E 两步搜索发现，单个高次数候选可能令整个分片长时间不能提交。因此长任务
升级为候选级 `euclid-min-durable-search-journal/v1`：

1. 首行保存不可变任务定义；profile、输入、算法代码和配置共同决定任务签名；
2. 每完成一个首步候选，主进程立即追加一条结果、`flush` 并 `fsync`；
3. 每条事件包含序号、前一事件摘要和自身 SHA-256，形成可校验哈希链；
4. 死机留下的 EOF 半条记录会在恢复时舍弃；日志中部损坏或哈希链断裂则拒绝续跑；
5. `Ctrl+C` 会终止尚未完成的 worker，并保留所有已经提交的候选；重复同一命令恢复；
6. 严格实区间不能判定的目标入射式以 `deferred` 记录持久化，不得当作“不命中”；
7. 只有所有候选完成、没有命中且 `deferred` 为零，摘要才可标记为精确穷尽。

旧分片检查点中已完成的 49 片（1,568 个候选）由 v2 按来源文件 SHA-256、原任务
签名和具体候选区间导入，不会重算或伪装成 v2 原生结果。正式日志位于
`benchmarks/e16-two-step-target-extension-checkpoint-v2-sage-10.7.jsonl`。

## 7. 下一步

固定 16E 后的全部两笔路线已经关闭。继续寻找 18E 时，应把改动窗口向前移动：

1. **把 13–16E 的 `M0_4` 定位宏从 4E 降到 3E**：若保持后三笔不变，也会得到
   18E。新 IR 允许只要求宏的外部代数接口，不强制模仿现有三个中间点名。
2. **改写二次分解和载体**：利用 `eta2_4、eta3_4、eta0_8` 三个免费兄弟根，搜索
   能同时服务后续定位和目标转移的共享直线或圆。

后续不再扩大同一个固定 E16 尾部窗口，而转入更早的接口驱动合成或共享痕迹改写。
任何新窗口仍先建立可恢复的有限覆盖，再决定是否值得扩大。

## 8. 复现

生成 IR：

```bash
PYTHONPATH=/workspace/sage sage -python \
  sage/experiments/build_regular17_geometry_algebra_ir.py
```

运行或恢复固定 17E 一步搜索：

```bash
PYTHONPATH=/workspace/sage sage -python \
  sage/experiments/search_e17_one_step_target_extension.py
```

演示只完成一个新分片后暂停：

```bash
PYTHONPATH=/workspace/sage sage -python \
  sage/experiments/search_e17_one_step_target_extension.py --max-shards 1
```

再次运行同一命令（去掉 `--max-shards`）即可从检查点继续。

运行或恢复固定 16E 两步搜索：

```bash
PYTHONPATH=/workspace/sage sage \
  sage/experiments/search_e16_two_step_target_extension_v2.py --workers 8
```

用有限候选演示暂停与恢复：

```bash
PYTHONPATH=/workspace/sage sage \
  sage/experiments/search_e16_two_step_target_extension_v2.py \
  --workers 8 --max-candidates 8
```

再次执行同一命令会跳过日志中已经完成的候选。运行中的任务可用 `Ctrl+C` 安全
暂停；整机或 Docker 异常退出后也使用同一命令恢复。
